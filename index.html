What's here

Survival, the honest way

Vanilla-style survival. Build your base, explore, trade with other players. No pay-to-win, no gimmicks.

Small & friendly

A community server where everyone knows each other. New players are welcome — say hi in chat.

Run by a real person

Hosted by the owner, not a company. The server may sleep at odd hours — if you can't connect, try again later.

How to join

1

Open Minecraft Java Edition and click Multiplayer.

2

Click Add Server and paste play.fezzy.org.uk into the address box.

3

Click Done, then double-click the server to join. That's it.

Rules

  • Be decent to each other. Banter is fine, bullying is not.
  • No griefing or stealing from other players' builds.
  • No hacked clients, x-ray, or dupe exploits.
  • Keep chat clean — younger players are around.
  • Build at least 100 blocks from someone else's base unless they invite you.

Server status

The server is player-hosted, so it isn't online 24/7. If you can't connect, it's probably just asleep — check back soon or ask in the community chat when it'll be up.
